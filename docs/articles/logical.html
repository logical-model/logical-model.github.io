logical produces quantitative predictions from the logical model of minority representation developed in Atsusaka (2021). The model describes the probability that a minority candidate emerges and wins in a district. It is intended as a tool for examining assumptions and scenarios; the article’s validation results describe the samples it evaluated, rather than a guaranteed accuracy rate for every new election or district plan.

The model and its inputs

The model prediction is

\[ \Pr(\text{minority candidate emerges and wins}) = \Phi\left(\sqrt{MC} - 50\right), \]

where \(\Phi\) is the standard normal cumulative distribution function, M is the adjusted racial margin of victory, and C is the minority share of the electorate. Both M and C use a 0–100 scale.

M summarizes the electoral environment using the top minority and White candidate vote shares in the previous election. C is the percentage of the electorate that is part of the minority group. When turnout differs between minority and White voters, supply gap = c(minority_turnout, white_turnout); each turnout rate is a proportion from 0 to 1.

Predicting outcomes in districts

Here are predictions for three districts with known M and C values.

M <- c(20, 50, 30)
C <- c(40, 70, 85)

prediction <- minorep(M = M, C = C)
round(prediction, digits = 4)
#> [1] 0.0000 1.0000 0.6906

minorep() returns full-precision probabilities. Rounding is useful for a table or label, but is best deferred until presentation.

If the minority and White turnout rates are 0.5 and 0.6, respectively, use the optional gap argument. The package adjusts C before calculating the prediction.

prediction_with_gap <- minorep(
  M = M,
  C = C,
  gap = c(0.5, 0.6)
)
round(prediction_with_gap, digits = 4)
#> [1] 0.0000 1.0000 0.4039

Deriving or simulating the racial margin

When candidate vote shares are available, calculate M directly with comp_M(). The inputs are the vote shares (0–100) of the top minority and White candidates.

top_minority <- c(18, 40, 85, 20)
top_white <- c(60, 40, 10, 34)

observed_M <- comp_M(Vm = top_minority, Vw = top_white)
observed_M
#> [1] 29.0 50.0 87.5 43.0

For a prospective scenario, sim_M() obtains M from C and two voting assumptions. coethnic is the share of minority voters expected to support the minority candidate; crossover is the analogous share of White voters. Both are proportions from 0 to 1.

hypothetical_C <- c(40, 50, 60)
simulated_M <- sim_M(
  C = hypothetical_C,
  coethnic = 1,
  crossover = 0.3
)
simulated_M
#> [1] 58 65 72

round(minorep(M = simulated_M, C = hypothetical_C), digits = 4)
#> [1] 0.0334 1.0000 1.0000

Simulating jurisdiction-level counts

Use n_minorep() to turn district-level probabilities into possible counts of minority officeholders in a jurisdiction. The function performs independent Bernoulli draws for each district. Set seed to make a simulation reproducible without changing the caller’s random-number state.

district_M <- c(50, 40, 40, 35, 70, 85)
district_C <- c(50, 40, 60, 30, 50, 80)
district_prediction <- minorep(M = district_M, C = district_C)

count_draws <- n_minorep(
  model_pred = district_prediction,
  n_sim = 1000,
  seed = 2026
)
summary(count_draws)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#>   2.000   2.000   3.000   2.659   3.000   4.000
hist(
  count_draws,
  xlab = "Simulated number of minority officeholders",
  main = ""
)

Comparing redistricting scenarios

sim_redistrict() calculates model predictions as C changes from 1 to 100 percent in increments of 0.1 percentage points. Create a column for each scenario and pass that matrix to plot_redistrict(). The range argument uses electorate percentages, not vector positions.

plan_1 <- sim_redistrict(coethnic = 0.9, crossover = 0)
plan_2 <- sim_redistrict(coethnic = 0.9, crossover = 0.3)
plan_3 <- sim_redistrict(coethnic = 0.9, crossover = 0.5)

plans <- cbind(
  "No crossover" = plan_1,
  "Moderate crossover" = plan_2,
  "High crossover" = plan_3
)

plot_redistrict(plans = plans, range = c(44, 55))

Finding a scenario’s sweet spot

The sweet spot is the first minority electorate percentage at which a scenario reaches a chosen probability threshold. C.prime marks a district of interest: a value below the sweet spot indicates a shortfall and a value above it a surplus. It must lie within the displayed range.

plan <- sim_redistrict(coethnic = 0.9, crossover = 0.2)

plot_sweetspot(
  plan = plan,
  threshold = 0.8,
  range = c(30, 70),
  C.prime = 70
)
