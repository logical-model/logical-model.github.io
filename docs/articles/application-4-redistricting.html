Application 4: comparing redistricting scenarios

sim_redistrict() calculates predictions as the minority electorate share changes from 1 to 100 percent in 0.1-point increments. Each vector has 991 values. Give each scenario a named column, then pass the matrix to plot_redistrict().

plan_1 <- sim_redistrict(coethnic = 0.9, crossover = 0)
plan_2 <- sim_redistrict(coethnic = 0.9, crossover = 0.3)
plan_3 <- sim_redistrict(coethnic = 0.9, crossover = 0.5)

plans <- cbind(
  "No crossover" = plan_1,
  "Moderate crossover" = plan_2,
  "High crossover" = plan_3
)
plot_redistrict(plans = plans, range = c(44, 55))

range uses electorate percentages, not vector positions. The plot uses the column names in its legend and can compare one or more scenarios.
