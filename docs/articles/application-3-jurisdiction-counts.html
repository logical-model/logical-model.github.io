Application 3: jurisdiction-level counts

n_minorep() converts district-level probabilities into simulated counts of minority officeholders across a jurisdiction. It makes independent Bernoulli draws for every district in each simulation.

district_M <- c(50, 40, 40, 35, 70, 85)
district_C <- c(50, 40, 60, 30, 50, 80)
district_prediction <- minorep(M = district_M, C = district_C)

count_draws <- n_minorep(
  model_pred = district_prediction,
  n_sim = 1000,
  seed = 2026
)
summary(count_draws)
hist(count_draws, xlab = "Simulated number of minority officeholders", main = "")

n_sim controls the number of returned draws. Supplying seed makes a result reproducible without changing the caller's random-number state. The distribution represents uncertainty implied by the supplied district-level probabilities.
