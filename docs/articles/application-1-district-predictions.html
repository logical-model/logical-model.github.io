Application 1: district-level predictions

Use minorep() when the adjusted racial margin of victory (M) and minority electorate share (C) are known for one or more districts. Both are percentages from 0 to 100.

M <- c(20, 50, 30)
C <- c(40, 70, 85)
prediction <- minorep(M = M, C = C)
round(prediction, digits = 4)

Adjusting for turnout differences

If minority and White turnout rates are known, pass them in that order through gap. Rates are proportions, not percentages.

prediction_with_gap <- minorep(
  M = M, C = C, gap = c(0.5, 0.6)
)
round(prediction_with_gap, digits = 4)

The turnout adjustment changes the effective minority share of the electorate before the model calculates the probability.
