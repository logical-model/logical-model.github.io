Application 2: calculating and simulating the racial margin

The adjusted racial margin of victory, M, can be calculated from observed election returns or simulated from voting assumptions.

Observed vote shares

top_minority <- c(18, 40, 85, 20)
top_white <- c(60, 40, 10, 34)
observed_M <- comp_M(Vm = top_minority, Vw = top_white)
observed_M

Prospective scenarios

sim_M() derives M from the minority electorate share, coethnic voting, and White crossover voting. The latter two inputs are proportions from 0 to 1.

hypothetical_C <- c(40, 50, 60)
simulated_M <- sim_M(
  C = hypothetical_C, coethnic = 1, crossover = 0.3
)
round(minorep(M = simulated_M, C = hypothetical_C), digits = 4)

Make voting assumptions explicit and substantively defensible; varying them reveals how a scenario depends on voting behavior.
