# logical-model.github.io

The public documentation site for the [`logical`](https://github.com/YukiAtsusaka/logical)
R package and its model of minority representation.

The site is published from the `docs/` directory with GitHub Pages. Its source
vignette is maintained in the package repository at
[`vignettes/logical.Rmd`](https://github.com/YukiAtsusaka/logical/blob/master/vignettes/logical.Rmd).
