# logical-model.github.io

The public documentation site for the
[`logical`](https://github.com/YukiAtsusaka/logical/tree/codex/cran-readiness)
R package and its model of minority representation.

The site is published from the `docs/` directory with GitHub Pages. Its source
vignettes are maintained in the package repository's
[`vignettes/`](https://github.com/YukiAtsusaka/logical/tree/codex/cran-readiness/vignettes)
directory.
